# Offix (mesNation) — корпоративный мессенджер и CRM

| Папка | Что внутри |
|-------|-----------|
| `server/` | API, сообщения в реальном времени и раздача сайта — Express 5 + PostgreSQL + Socket.IO ([README](server/README.md)) |
| `web/` | Веб-версия (React + Vite). В продакшене собирается и раздаётся сервером |
| `mobile/` | Мобильное приложение (React Native, Android/iOS) |
| `deploy/windows/` | Скрипты установки, обновления, диагностики и резервного копирования на Windows-сервере |
| `docs/` | Документация: [развёртывание](docs/DEPLOY.md), концепция CRM, планы |

Сайт, API и сокеты работают с одного адреса через один процесс Node.
Как это устроено и как развернуть на сервере компании — [docs/DEPLOY.md](docs/DEPLOY.md).
