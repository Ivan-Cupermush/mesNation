# Push-уведомления Offix: подключение Firebase

Уведомления уже работают **без настройки**, пока приложение запущено или свёрнуто
(через соединение с сервером). Чтобы они приходили и когда приложение **закрыто**,
нужен бесплатный проект Firebase — один раз, примерно 10 минут.

## 1. Проект Firebase

1. Откройте <https://console.firebase.google.com> → **Add project** (Создать проект).
   Название любое, например `Offix`. Google Analytics можно выключить.
2. В проекте: **Add app → Android**.
   - **Android package name:** `com.mesnation` (обязательно ровно так).
   - Остальное можно не заполнять → **Register app**.
3. Скачайте файл **google-services.json**.

## 2. Файл для сборки APK (GitHub)

Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:

- **Name:** `GOOGLE_SERVICES_JSON`
- **Secret:** содержимое файла `google-services.json` целиком (можно и в base64).

Следующая сборка APK подключит Firebase автоматически — в журнале сборки будет строка
«Firebase подключён».

## 3. Ключ для сервера

1. В консоли Firebase: ⚙ **Project settings → Service accounts → Generate new private key**.
   Скачается JSON-файл — это секретный ключ, не публикуйте его.
2. Положите файл на сервер (например, `/opt/offix/firebase-key.json`) и добавьте в `.env` сервера:

   ```
   FIREBASE_SERVICE_ACCOUNT=/opt/offix/firebase-key.json
   ```

   (или вставьте содержимое JSON целиком в одну строку).
3. Перезапустите сервер. В логе появится «Push-уведомления включены (Firebase)».

## Проверка

В приложении: **Профиль → Уведомления**. Вверху будет зелёная плашка
«Уведомления приходят, даже когда приложение закрыто». Там же — кнопки
«Показать уведомление о сообщении / задаче», чтобы посмотреть, как они выглядят.

## Что приходит

| Событие | Кому | Как выглядит |
|---|---|---|
| Новое сообщение | участникам чата, кроме автора и тех, у кого чат «Без звука» | как в Telegram: аватар, название чата, последние сообщения, «Ответить» и «Прочитано» прямо из шторки |
| Новая задача | исполнителям | канал «Задачи», цвет приоритета, срок и автор, кнопки «Взять в работу» / «Открыть», двойная вибрация |
| Задачу сдали на проверку | наблюдателям и создателю | «Принять» и «Вернуть» (с причиной) прямо из шторки |
| Задачу вернули / приняли / открыли снова | исполнителям | с комментарием проверяющего |

Прочитали чат на одном устройстве — его уведомления исчезают и на остальных.
При смене пароля, «выйти на всех устройствах» и деактивации сотрудника телефоны
отвязываются от уведомлений.
